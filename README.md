# 모두의 탐구의 맥 · 선생님의 학생 탐구 상담 길잡이

학교생활기록부 PDF를 올리면 세부능력 및 특기사항·창의적 체험활동에 적힌 탐구를 **교과군 × 학기** 위에 펼치고,
어떤 탐구가 어떤 이유로 이어졌는지(심화·확장·전환·반복), 얼마나 깊어졌는지(1~4단계)를 계보도로 보여 주는 교사용 상담 도구입니다.
AI를 쓰지 않고 규칙과 어휘 사전(약 14,000개 낱말·표현)으로 판단합니다.

- 바로 쓰기: https://park-sanggeun-all.github.io/tamgu-maek/
- 사용 설명서: [manual.pdf](manual.pdf) · 앱 안의 **? 설명서** 버튼

## 주요 기능
- **탐구 계보도** — 학기별·교과군별 카드, 연결선과 연결 이유, 같은 기록 안의 추가 탐구, 성취도·등급 표시
- **탐구 방법** — 학기별·교과군별 방법 표, 칸을 누르면 근거 문장과 함께 옆 창에 목록
- **상담 노트** — 자동 상담 포인트(강점·점검·질문·방향), 학생별·기록별 메모
- **표현 사전** — 놓친 표현을 선생님이 직접 추가(이 컴퓨터에 저장, 내보내기·가져오기 가능)
- 한 반 전체를 묶은 PDF도 학생별로 자동으로 나눠 불러옵니다.

## 개인정보와 보안
- **외부 전송 없음** — 학생부 PDF는 선생님 브라우저 안에서만 읽고 분석합니다. 서버·클라우드·AI 서비스로 보내지 않습니다.
- **통신 차단** — `index.html`에 Content-Security-Policy(`connect-src 'none'` 등)가 걸려 있어 외부와의 통신 자체가 막혀 있습니다. 글꼴과 PDF 처리 라이브러리(pdf.js)도 파일 안에 들어 있어 오프라인에서도 동작합니다.
- **GitHub Pages로 배포해도 안전** — 서버는 이 HTML 파일만 내려보낼 뿐, 선생님이 올린 PDF나 분석 결과를 받지 못합니다.
- **저장하지 않음** — 분석 결과와 메모는 브라우저 메모리에만 있고 창을 닫으면 사라집니다. 브라우저에는 선생님이 추가한 ‘표현 사전’ 낱말만 저장됩니다.
- **포함된 데이터** — 예시 학생(김하람)은 가상 인물입니다. 낱말 통계에는 학생 이름이나 학교명이 들어 있지 않습니다.

### 선생님이 꼭 지켜 주세요
- ‘작업 저장’ 파일(.json), 인쇄물, PDF로 저장한 화면에는 학생 개인정보가 들어 있습니다. 학교 지침에 따라 보관·파기해 주세요.
- **이 저장소에 학생부 PDF나 작업 파일을 절대 올리지 마세요.** `.gitignore`가 PDF·JSON 등을 막아 줍니다(설명서 `manual.pdf`만 예외).
- 공용 컴퓨터에서는 상담 후 **모두 지우기**를 누르거나 창을 닫아 주세요.

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소 **`tamgu-maek`** 을 만듭니다(Public).
2. 이 폴더의 파일을 모두 올립니다: `index.html`, `og-image.png`, `manual.pdf`, `README.md`, `.gitignore`, `.nojekyll`
   - 웹에서 올릴 때: 저장소 → **Add file → Upload files** 로 파일을 끌어다 놓고 **Commit changes**.
   - `.gitignore`, `.nojekyll`처럼 점으로 시작하는 파일이 안 보이면 탐색기에서 ‘숨긴 항목 보기’를 켜 주세요.
3. 저장소 **Settings → Pages** 에서 Source를 *Deploy from a branch*, Branch를 `main` / `(root)`로 고르고 **Save**.
4. 1~2분 뒤 https://park-sanggeun-all.github.io/tamgu-maek/ 주소로 열립니다.
5. 새 버전으로 바꿀 때는 `index.html`만 다시 올리면 됩니다.
